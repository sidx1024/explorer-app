## Submission options: restricted capability justification (runFullTrust)

> Explorer App is a native Win32 desktop file manager (Rust, Direct2D, Windows Shell APIs) packaged with MSIX. runFullTrust is required to browse and manage the user's files with the standard Windows shell (file operations, context menus, thumbnails and preview handlers). It doesn't access the network.

## Store listing (English)

**Product name:** Explorer App

**Short description** (shown in some views, ≤ 270 characters):

> A fast file explorer that looks and feels like Windows 11 File Explorer, with instant search across your drives, tabs, thumbnails and a preview pane. No AI features, no cloud, no accounts.

**Description:**

> Explorer App is a fast file explorer for Windows that looks and feels like the built-in File Explorer, without the wait.
>
> • Instant search: type and see matches from your whole drive in milliseconds, with filters for date, type, size and system files.
> • Tabs, breadcrumbs, back/forward, and a navigation pane that shares your Quick access pins with File Explorer.
> • Every view: extra large to small icons, list, details with sortable and resizable columns, and tiles with drive usage.
> • Thumbnails for photos, videos, PDFs and anything else Windows can preview, cached so folders open instantly next time.
> • Preview pane for images, text and code, plus the same preview handlers File Explorer uses (PDF, Office and more).
> • The full Windows context menu with your installed extensions, native copy/move/delete dialogs, drag and drop, cut and paste.
> • Remembers the view, sort order and column widths of every folder.
> • Fits right into Windows 11: Mica, light and dark themes, Snap Layouts, high contrast.
> • No AI features, no cloud, no accounts, no telemetry.
> • Tiny: under 1 MB.
